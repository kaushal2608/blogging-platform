DevOps Architecture Stack

  • Infrastructure: AWS (VPC, Public/Private Subnets, IGW, NAT Gateway, Security Groups)
  • IaC: Terraform
  • Configuration Management: Ansible
  • CI/CD Automation: Jenkins (Master on Bastion, Application Node)
  • Containerization: Docker & Docker Compose (Docker Hub Registry)
  • Application Tier: Node.js Express REST API (Port 5000)
  • Frontend Tier: Nginx Web Server / Static HTML (Port 80)
  • Database Tier: MySQL 8.0 in Private Subnet (Port 3306)
